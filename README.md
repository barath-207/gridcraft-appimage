# GridCraft AppImage

Unofficial community-built Linux x86_64 AppImages for [GridCraft](https://github.com/storytold/gridcraft).

Download the latest AppImage from the [Releases](https://github.com/barath-207/gridcraft-appimage/releases) page.

Builds are published automatically by [ArtCraft AppImage Builder](https://github.com/barath-207/Artcraft-appimage-builder).
